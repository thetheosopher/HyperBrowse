# Nature Screenshot Dataset

This small image set is used to create reproducible HyperBrowse screenshots.
The images are downloaded from the USGS Multimedia Gallery at its Medium
rendition size. Each linked USGS image record marks its source usage as
**Public Domain**. USGS asks users to credit its material; see its
[copyright and credit guidance](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits).
